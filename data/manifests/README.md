# Manifest Notes

This directory now contains two different kinds of manifest:

- Curated split manifests:
  - `train_manifest.csv`
  - `val_manifest.csv`
  - `test_field_manifest.csv`
- Generated cache manifest:
  - `events_manifest.csv`

The curated split manifests define the V1 dataset contract for Common Wood Pigeon and Eurasian Wren.
They operate at the recording level and should be edited by hand or with a future curation tool.

`events_manifest.csv` is different. It is generated by the segmentation pipeline and should be treated as a cache artifact, not as the source of truth for train/validation/test splits.

## Required Columns

- `recording_id`: stable identifier for the full recording
- `audio_path`: path to the source recording, usually under `data/raw/`
- `species_label`: one of the labels from `config/v1_species.yaml`
- `species_common_name`: human-readable species name
- `scientific_name`: scientific species name
- `species_source`: where the species label came from, for example `manual_review`
- `recording_source`: `web` or `field`
- `split`: `train`, `val`, or `test_field`
- `notes`: optional free-text notes
